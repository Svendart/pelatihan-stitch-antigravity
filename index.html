About Me

Tentang Saya

Mengenal lebih dekat latar belakang dan semangat belajar seorang siswa kejuruan perangkat lunak.

Halo! Saya Ahsan, siswa SMK kelas 11 program keahlian Pengembangan Perangkat Lunak dan Gim (PPLG). Saya memiliki ketertarikan mendalam dalam mengeksplorasi dunia software development, logika algoritma, dan perancangan aplikasi.

"Portofolio ini merupakan dokumentasi perjalanan belajar, eksperimen, dan proyek yang sedang dikembangkan secara jujur apa adanya sebagai pelajar."

Bagi saya, menjadi seorang siswa kejuruan bukan hanya tentang menghafal baris kode, melainkan tentang bagaimana memecahkan masalah langkah demi langkah (algorithmic thinking) dan memiliki keberanian untuk mencoba hal-hal baru tanpa takut menghadapi error.

🏫

Belajar Mandiri & Sekolah

Mengembangkan logika algoritma secara sistematis di ruang kelas, lalu melanjutkan eksplorasi tools kreatif, riset mandiri, dan proyek sampingan di waktu luang.

05 // FOCUS Web Tech

Meningkatkan Web Development

Memperdalam tata letak responsif, estetika modern dark mode, CSS Flexbox/Grid, dan interaktivitas JavaScript murni pada peramban web.

06 // FOCUS Preparation

Persiapan Menghadapi PKL

Membangun kedisiplinan kerja versi proyek (Git flow), komunikasi teknis, serta kesiapan mental untuk beradaptasi dan berkolaborasi di lingkungan industri.

Learning Path

Timeline Perjalanan Belajar

Tahap demi tahap proses mengenal teknologi dari awal masuk SMK PPLG hingga saat ini.

MILESTONE 01 // AWAL MULA

Mulai Mengenal Programming

Menemukan ketertarikan pada logika komputer, arsitektur software, dan teknologi digital saat pertama kali memasuki program keahlian PPLG di SMK.

MILESTONE 02 // LOGIKA & STRUKTUR

Belajar Python dan C++

Membangun pemahaman mendasar mengenai variabel, tipe data, kondisi logika (if-else), serta perulangan (loops) untuk menyelesaikan kalkulasi otomatis.

MILESTONE 03 // ANTARMUKA WEB

Mengenal Web Development

Mulai membuat struktur halaman web menggunakan semantik HTML5 dan menatanya dengan styling CSS modern, Flexbox, dan responsive design.

MILESTONE 04 // EKOSISTEM MOBILE

Mengerjakan Project Android

Mencoba Android Studio untuk pertama kalinya, memahami hubungan layout XML dengan file Kotlin/Java, dan berhasil merilis aplikasi interaktif Hello Toast.

MILESTONE 05 // KOLABORASI KODE

Belajar Git dan GitHub

Memahami pentingnya version control system, cara melakukan snapshot perubahan dengan commit, dan pemanfaatan branch untuk menjaga stabilitas branch utama.

MILESTONE 06 // EKSPLORASI LANJUTAN

Mengeksplorasi AI dan Multimedia

Menjelajahi konsep dasar otomatisasi Python untuk penerapan AI serta mempelajari timeline grafis dinamis menggunakan Adobe Animate.

MILESTONE 07 // SINTESIS KREATIF

Mengembangkan Creative Work

Menggabungkan daya imajinasi lewat gambar visual digital/tradisional dan penulisan cerita pendek untuk memperkaya perspektif estetika dalam pengembangan produk.
